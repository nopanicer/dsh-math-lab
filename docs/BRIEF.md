# 24 个模型的作业单

> 写作前先读 `docs/CONTRACT.md` 和 `src/models/quadratic.js`。
> 每个模型一个文件 `src/models/<id>.js`，参数/动画/读数/副图/出题/例题都写在里面。
> 下面给的是**教学意图与最低要求**，具体画法可以更好，但不能更少。

---

## A 组 · 高一 函数与三角

### A1 `graphTransform` 函数图像变换 / Function transformations
- 参数：`base`（select：x²、|x|、√x、1/x、x³）、`a`（纵向伸缩 0.5–2）、`b`（横向伸缩 0.5–2）、`h`（横向平移 −4–4）、`k`（纵向平移 −4–4）
- 主图：虚线画原函数 f(x)，实线画 y = a·f(b(x − h)) + k；关键点 (0,0)、(1,1) 等映射后的像用不同颜色标出
- 动画主线：用进度把图像从 f(x) **连续变形**到最终形态（先后顺序自定，但讲解要对应），`state` 里给出当前中间形态
- 读数：当前阶段、原函数、目标解析式、某个关键点的像
- 副图 `chartValue`：中间曲线的某个特征值（如 x = 0 处的值），必须随时间变化
- 出题：给定 base/a/b/h/k，求 x = x₀ 处的函数值；或求顶点/对称轴/渐近线（数值即可）
- 例题：从 y = x² 平移到 y = (x − 2)² + 3，问顶点纵坐标或某点函数值

### A2 `expLog` 指数与对数 / Exponential & logarithm
- 参数：`a`（底数 0.3–3，避开 1）、`x0`（观察点 −2–3）
- 主图：y = aˣ 与 y = log_a x（关于 y = x 对称），虚线 y = x；动点 P(x, aˣ) 与其镜像 Q(aˣ, x)
- 动画：P 沿曲线从左向右走，Q 同步镜像移动
- 读数：aˣ、log_a(x)、定义域/值域、单调性、两曲线交点 (a^?) 说明
- 副图：动点的 y 值
- 出题：求 log_a N、求 aˣ、判断 a > 1 还是 a < 1（用数值：给出 log_a N 求 N）
- 例题：log₂ 8、2^0.5 之类

### A3 `trigGraph` 三角函数图像 / y = A sin(ωx + φ) + k
- 参数：`A`（0.5–3）、`omega`（0.5–3）、`phi`（−1–1，单位是 π）、`k`（−2–2）
- 主图：曲线 + 平衡线 y = k + 振幅/周期标注 + 「五点法」五个关键点 + 扫描点
- 动画：扫描点沿一个周期移动（或相位连续推进），读数跟着变
- 读数：周期 T = 2π/ω、频率、振幅 |A|、最大值、最小值、当前相位、当前 y
- 副图：当前 y 值
- 出题：求周期、求最大值/最小值、求给定 x 处的函数值
- 例题：y = 2sin(2x + π/3) 的周期/最大值

### A4 `trigIdentity` 三角恒等与单位圆 / Angle addition on the unit circle
- 参数：`alpha`（0–80°，5° 步长）、`beta`（0–80°）
- 主图：单位圆 + 角 α、β、α+β 的终边 + sin/cos 投影线；用两个直角三角形拼出
  sin(α+β) = sinα·cosβ + cosα·sinβ 的几何意义
- 动画：β 从 0 连续增大到参数值，终边扫过，读数实时更新
- 读数：sinα、cosα、sinβ、cosβ、sin(α+β)、cos(α+β)、公式右边两项
- 副图：sin(α + β(t))
- 出题：给定 α、β，求 sin(α+β) 或 cos(α−β)
- 例题：sin75° = sin(45°+30°)

## B 组 · 高一 向量与解三角形

### B1 `vector` 平面向量 / Vectors
- 参数：`la`（|a| 1–5）、`lb`（|b| 1–5）；夹角 θ 由动画从 0° 连续扫到 180°
- 主图：以原点为起点的 a、b；平行四边形法则画 a + b；虚线画 a − b；b 在 a 上的投影
- 动画：θ(t) 匀速增大，a·b 从正变 0 再变负，|a + b| 在 θ = 90° 附近取到特定值
- 读数：θ、cosθ、a·b、|a + b|、|a − b|、投影长度
- 副图：a·b 随 θ 的变化
- 出题：给定 |a|、|b|、θ 求 a·b / |a + b|
- 例题：|a|=2、|b|=3、夹角 60° 求 a·b 和 |a+b|

### B2 `triangle` 解三角形 / Solving triangles
- 教学点：正弦定理 a/sinA = b/sinB = c/sinC = 2R
- 参数：`a`（边 BC 长 2–6）、`A`（顶角 30°–110°）
- 主图：弦 BC 固定，顶点 A 在以 BC 为弦的圆弧上滑动（同弦同角）；画外接圆与半径 R
- 动画：A 沿圆弧移动，∠A 保持不变，b、c 与面积变化，而 a/sinA = 2R 不变
- 读数：∠A、b、c、R、a/sinA、面积
- 副图：面积随 A 的位置变化
- 出题：正弦定理、余弦定理（给定两边夹角求第三边、求角）
- 例题：a=4、A=30°，求外接圆半径

### B3 `inequality` 基本不等式 / AM–GM inequality
- 参数：`a`、`b`（正数 0.5–6）
- 主图：经典半圆图 —— 直径 = a + b，半径 R = (a+b)/2，垂直半弦高 h = √(ab)，显示 R ≥ h
- 动画：和 s = a + b 保持不变，让 a(t) 从 a 变到 b（b(t) = s − a(t)），h 增大到 R，等号成立
- 读数：a、b、a+b、2√(ab)、R、h、R − h、(a−b)²
- 副图：(a−b)² 或 R − h 随时间变化
- 出题：和定求积最大 / 积定求和最小 / 求某式最小值
- 例题：x > 0 时 x + 1/x 的最小值

## C 组 · 高二 解析几何

### C1 `lineCircle` 直线与圆 / Line and circle
- 参数：`r`（半径 1–5）、`k`（斜率 −3–3）；直线截距 b 由动画从远到近扫过
- 主图：圆 + 直线 + 圆心到直线垂线（距离 d）+ 弦与弦心距；相交/相切/相离三种状态
- 动画：直线平行移动到 b 扫描，经过相离 → 相切 → 相交
- 读数：d、r、位置关系、弦长 = 2√(r² − d²)、切线条件
- 副图：弦长随时间
- 出题：求弦长、判断位置关系（用数值：弦长或距离）、求切线斜率
- 例题：圆 x²+y²=25 被直线 3x+4y−5=0 截得弦长

### C2 `ellipse` 椭圆 / Ellipse
- 参数：`a`（长半轴 2–6）、`c`（半焦距 0–a−0.2）
- 主图：椭圆 + 两焦点 + 动点 P + 焦半径 r₁、r₂；标出 a、b、c
- 动画：P 沿椭圆一周，r₁ + r₂ 恒为 2a
- 读数：a、b、c、e、r₁、r₂、r₁+r₂、通径
- 副图：r₁ 或 r₂ 随参数角的变化
- 出题：求离心率、求 b、求通径
- 例题：a=5、c=3 求 e 和 b

### C3 `hyperbola` 双曲线 / Hyperbola
- 参数：`a`（实半轴 1–4）、`c`（半焦距 a+0.2–6）
- 主图：双曲线右支（或两支）+ 焦点 + 渐近线 + 动点 P 与焦半径
- 动画：P 沿右支移动，|r₁ − r₂| = 2a 保持
- 读数：a、b、c、e、渐近线方程、|r₁ − r₂|、顶点
- 副图：r₁ − r₂（应稳定在 ±2a，展示性质）
- 出题：求渐近线斜率、求离心率、求 b
- 例题：x²/9 − y²/16 = 1 的渐近线与离心率

### C4 `parabola` 抛物线 / Parabola
- 参数：`p`（焦准距 0.5–6）、`dir`（select：开口向右/向左/向上/向下）
- 主图：抛物线 + 焦点 + 准线 + 动点 P + PF 与到准线距离
- 动画：P 沿抛物线移动，|PF| = 到准线距离
- 读数：方程、焦点坐标、准线方程、|PF|、到准线距离、通径
- 副图：|PF| 随参数变化
- 出题：求焦点/准线/焦半径
- 例题：y² = 8x 的焦点与通径长

## D 组 · 高二 导数与数列

### D1 `derivative` 导数与切线 / Derivative as a limit
- 参数：`fn`（select：x²、x³、1/x、sin x、eˣ）、`x0`（−3–3，避开奇点）
- 主图：曲线 + 点 P(x0, f(x0)) + 割线 P-Q(Q 在 x0 + h) + 切线
- 动画：h 从 2 减到 0.01（对数尺度），割线连续转到切线
- 读数：f(x0)、h、割线斜率、切线斜率 f′(x0)、切线方程
- 副图：割线斜率随 h 的变化（收敛到 f′(x0)）
- 出题：求 f′(x0)、求切线方程斜率、求割线斜率
- 例题：f(x)=x² 在 x=1 处的切线方程（答案给斜率或截距）

### D2 `monotonic` 导数与单调性 / Monotonicity and extrema
- 参数：`a`（−2–2）、`b`（−3–3）、`c`（−3–3）；f(x) = ax³ + bx² + cx
- 主图：f(x) 曲线 + f′(x) 曲线（另一颜色）+ 极值点 + 单调区间底色
- 动画：扫描点 x 沿轴移动，实时显示 f′(x) 的符号与切线方向
- 读数：f′(x) 判别式、极值点坐标、单调递增/递减区间、极值
- 副图：f′(x) 随扫描点
- 出题：求极值点横坐标、判断单调区间、求 a 的范围使 f 单调（数值）
- 例题：f(x)=x³−3x 的极值

### D3 `integral` 定积分与面积 / Definite integral
- 参数：`fn`（select：x²、√x、sin x、eˣ）、`b`（上限 0.5–3）
- 主图：曲线 + 区间 [0,b] 上的黎曼和矩形 + 曲边梯形填充
- 动画：分割数 n 从 1 增到 64（对数步进），矩形越来越贴合曲线
- 读数：n、黎曼和、定积分精确值、误差
- 副图：误差随 n 的变化（对数感）
- 出题：求定积分值
- 例题：∫₀¹ x² dx

### D4 `series` 数列 / Sequences and sums
- 参数：`kind`（select：等差/等比）、`a1`（−3–3）、`d` 或 `q`（−2–2，避开 1）、`n`（3–15）
- 主图：点列 (n, aₙ) + 前 n 项和的折线 + 通项公式
- 动画：n 从 1 增加到参数 n，逐项累加
- 读数：aₙ、Sₙ、公差/公比、单调性/收敛性
- 副图：Sₙ 随项数
- 出题：求 aₙ、求 Sₙ
- 例题：等差 a₁=2、d=3 求 S₁₀

## E 组 · 高三 计数与概率

### E1 `binomial` 排列组合与二项式 / Binomial theorem
- 参数：`n`（3–10）、`k`（0–n，用动画扫过）
- 主图：杨辉三角（n 行，数字小字）+ 第 n 行高亮 + 二项展开系数柱状图
- 动画：k 从 0 扫到 n，高亮 C(n,k) 与对应项
- 读数：C(n,k)、A(n,k)、C(n,k) 的数值、系数和 2ⁿ、最大系数项
- 副图：C(n, k(t))
- 出题：求 C(n,k)、A(n,k)、展开式中 x^k 的系数
- 例题：(x+1)⁵ 中 x² 的系数

### E2 `probability` 二项分布 / Binomial distribution
- 参数：`n`（5–20）、`p`（0.05–0.95）、`k`（0–n）
- 主图：P(X = k) 柱状图（k = 0…n）+ 累计概率阴影
- 动画：k 从 0 扫到参数 k，累计概率上升
- 读数：E(X)=np、D(X)=np(1−p)、P(X=k)、P(X≤k)、最可能值
- 副图：P(X = k(t))
- 出题：求 P(X=k)、E(X)、D(X)
- 例题：X~B(10, 0.3)，求 P(X=3)

### E3 `normal` 正态分布 / Normal distribution
- 参数：`mu`（−3–3）、`sigma`（0.4–2）、`lo`/`hi`（用 z 值区间或 ±kσ，select：±1σ/±2σ/±3σ）
- 主图：密度曲线 + 区间阴影 + μ 与 σ 标注 + 3σ 刻度
- 动画：区间右端从 μ 扫到 hi，累计概率（阴影）增大
- 读数：峰值、P(区间)、z 值、68.27%/95.45%/99.73% 对照
- 副图：累计概率 F(x)（S 形）
- 出题：求 P 值（用 erf 近似）、求对称区间概率
- 例题：X~N(0,1)，求 P(|X|<1)

### E4 `linearProgramming` 线性规划 / Linear programming
- 约束固定：x ≥ 0、y ≥ 0、x + y ≤ 6、2x + y ≤ 8；可行域顶点 (0,0)、(0,6)、(2,4)、(4,0)
- 参数：`c1`（目标函数 x 系数 −3–3）、`c2`（y 系数 −3–3）
- 主图：可行域填充 + 边界线 + 等值线（虚线，随动画平移）+ 最优解顶点高亮
- 动画：等值线从 z_min 平移到 z_max，最后接触最优顶点
- 读数：各顶点坐标与 z 值、最优解、最优值
- 副图：等值线常数随动画
- 出题：求目标函数最大值/最优解坐标
- 例题：z = 2x + 3y 在上述约束下的最大值

## F 组 · 高三 复数、立体几何、函数零点、统计

### F1 `complex` 复数与复平面 / Complex numbers
- 参数：`r1`、`theta1`（z 的模 0.5–4 与辐角 0–360°）、`r2`、`theta2`（w 的模与辐角）
- 主图：复平面 + z、w、z·w 三个向量 + 单位圆 + 共轭点
- 动画：把 z 连续乘以 w 的过程 —— 向量从 z 旋转到 z·w，模按 r₂ 缩放
- 读数：z 的实部/虚部/模/辐角、w 的、z·w 的、|z·w|、arg(z·w)
- 副图：旋转角随动画
- 出题：求 |z·w|、求 arg(z·w)、求 z·w 的实部
- 例题：(1+i)(√3+i) 的模与辐角

### F2 `solid3D` 立体几何（3D 视角）/ Solid geometry
- `has3D: true`、`noAxes: true`
- 参数：`a`（底面边长 2–6）、`h`（高 2–8）、`kind`（select：正四棱锥 / 正三棱柱）
- 主图：3D 线框（底面 + 顶点/棱）+ 高 + 侧棱 + 线面角的角标；拖动画面旋转
- 动画：相机缓慢自转（在 draw 里临时改 camera3D.yaw 再还原），或让高线/角标生长
- 读数：底面积、体积、侧棱长、线面角（度）、sin 值
- 副图：无坐标系，用 `chartValue` 表示「旋转角」或侧棱长；最好自己实现 `drawChart` 画一个角度示意图，或设 `noChart`
- 出题：求体积、求线面角正弦
- 例题：正四棱锥 P-ABCD，a=2、h=2 求 PA 与底面所成角

### F3 `zeros` 函数零点与二分法 / Zeros and bisection
- 参数：`fn`（select：x³ − 2x − 5、x² − 2、ln x + x − 3、eˣ − 3x）、`iters`（1–12）
- 主图：曲线 + 当前区间 [a,b] + 中点竖线 + 零点真值虚线
- 动画：二分迭代逐步收缩区间，每次迭代一次
- 读数：当前区间、中点、f(中点)、误差上界、迭代次数
- 副图：区间长度随迭代（对数下降）
- 出题：求零点近似（容差放宽）、判断 f(a)·f(b) 符号
- 例题：x³ − 2x − 5 = 0 在 [2,3] 内的近似解

### F4 `regression` 统计与回归 / Least squares
- 参数：`noise`（噪声 0–1）、`slope`（动画：拟合线斜率从 0 转到最小二乘解）
- 固定 8 个观测点 x = 1…8，y = 1.3x + 2 + noise·sin(i·1.7)
- 主图：散点 + 当前拟合直线 + 残差竖线 + 最小二乘直线（虚线对照）
- 动画：直线从水平转到最小二乘斜率，残差平方和下降
- 读数：斜率 b̂、截距 â、相关系数 r、残差平方和、x=8 处的预测值
- 副图：残差平方和随动画
- 出题：求斜率/截距/预测值（给定公式与数据表可直接算）
- 例题：给 5 组数据求回归直线斜率
